### About

I'm Eduardo — I've been designing and coding for the web since 2015. My work sits at the intersection of design and engineering: component libraries, animated interfaces, AI-powered tools, and the occasional side project just for fun.

I care about the details — easing curves, spacing, typography, the things that make software *feel* right.
